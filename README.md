# Keyboard Blackjack

iPad + 하드웨어 키보드로 즐기는 단일 HTML 블랙잭입니다. `index.html` 하나로 동작하며 외부 의존성이 없습니다.

- 룰: 6덱, 딜러 소프트 17 스탠드(S17), 블랙잭 3:2, 스플릿 후 더블(DAS), 레이트 서렌더, 최대 4핸드까지 스플릿, 스플릿 에이스는 한 장씩
- 스크롤 없는 한 화면 레이아웃(iPad Air 13" 1366×1024 기준, 세로 화면도 지원).
- 판이 끝나면 각 핸드 아래에 선택별 ✓/✗와 정답을 보여줍니다.
- `T`를 누르면 왼쪽에 통계(판 수, 승/패/푸시, 승률, 평균 손익률 = 총 손익 ÷ 총 기본 베팅, 전략 정확도), 오른쪽에 단축키가 나옵니다. 라운드 사이에 `X`를 두 번 누르면 초기화됩니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Enter` / `Space` | 딜 |
| `1`–`5` | 베팅 10 / 25 / 50 / 100 / 500 |
| `↑` / `↓` | 베팅 ±10 |
| `H` `S` `D` `P` `R` | 히트 / 스탠드 / 더블 / 스플릿 / 서렌더 |
| `I` / `N` | 인슈어런스(이븐머니) 받기 / 거절 |
| `X` `X` | 통계·잔액 초기화 |
| `T` / `?` | 통계 · 단축키 화면 |

## iPad에서 열기

GitHub Pages(Settings → Pages → 이 브랜치의 루트)로 배포한 뒤 Safari에서 열고 공유 → "홈 화면에 추가"를 하면 전체 화면으로 실행됩니다.
