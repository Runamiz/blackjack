# Keyboard Blackjack

iPad + 하드웨어 키보드로 즐기는 단일 HTML 블랙잭입니다. `index.html` 하나로 동작하며 외부 의존성이 없습니다.

- 룰: 6덱, 딜러 소프트 17 스탠드(S17), 블랙잭 3:2, 스플릿 후 더블(DAS), 레이트 서렌더, 최대 4핸드까지 스플릿, 스플릿 에이스는 한 장씩
- 스크롤 없는 한 화면 레이아웃(iPad Air 13" 1366×1024 기준, 세로 화면도 지원).
- 판이 끝나면 각 핸드 아래에 선택별 ✓/✗와 정답을 보여줍니다.
- `T`를 누르면 왼쪽에 통계(판 수, 승/패/푸시, 승률, 평균 손익률 = 총 손익 ÷ 총 기본 베팅, 전략 정확도), 오른쪽에 단축키가 나옵니다. 라운드 사이에 `X`를 두 번 누르면 초기화됩니다.

## 단축키

| 키 | 동작 |
|---|---|
| `Enter` / `Space` | 딜 |
| `1`–`5` | 베팅 10 / 25 / 50 / 100 / 500 |
| `↑` / `↓` | 베팅 ±10 |
| `H` `S` `D` `P` `R` | 히트 / 스탠드 / 더블 / 스플릿 / 서렌더 |
| `I` / `N` | 인슈어런스(이븐머니) 받기 / 거절 |
| `X` `X` | 통계·잔액 초기화 |
| `T` / `?` | 통계 · 단축키 화면 |

## iPad에서 열기

GitHub Pages(Settings → Pages → 이 브랜치의 루트)로 배포한 뒤 Safari에서 열고 공유 → "홈 화면에 추가"를 하면 전체 화면으로 실행됩니다.

# Killer Sudoku

`killer-sudoku/index.html` — iPad에서 터치, 하드웨어 키보드, 트랙패드로 즐기는 단일 HTML 킬러 스도쿠입니다. 외부 의존성이 없습니다.

- 퍼즐은 매번 새로 생성되며, 솔버로 **해가 하나뿐인지 검증**합니다. 처음부터 주어지는 숫자는 없고 케이지 합만 있습니다.
- 세로 화면: 상단 정보(난이도·시간) → 보드 → 도구(실행 취소·지우기·메모·힌트) → 숫자 줄. 가로 화면: 보드 왼쪽, 컨트롤 오른쪽.
- 메모 모드는 메모 버튼에 ON/OFF로 표시됩니다. 진행 상황, 타이머, 설정은 자동 저장됩니다. 라이트/다크 모드를 지원합니다.

## 설정 (⚙, 모두 기본 켜짐)

| 옵션 | 설명 |
|---|---|
| 실수 표시 안 함 | 끄면 정답과 다른 숫자를 빨간색으로 표시 (패널티 없음) |
| 중복 숫자 강조 | 행·열·블록(·케이지)에 같은 숫자가 있으면 칸을 붉게, 케이지 합이 넘치거나 맞지 않으면 합을 빨갛게 |
| 선택한 칸의 행·열·블록 강조 | |
| 같은 숫자 강조 | 선택한 칸과 같은 숫자와 메모를 강조 |
| 9개를 모두 채운 숫자 숨기기 | 숫자 버튼에서 숨김 |
| 메모 자동 지우기 | 숫자를 넣으면 같은 행·열·블록의 메모에서 그 숫자를 지움 |
| 케이지 조합 도우미 | 선택한 케이지에 들어갈 수 있는 숫자 조합 |

## 단축키

| 키 | 동작 |
|---|---|
| `1`–`9` | 숫자 입력 (같은 숫자를 다시 누르면 지움) |
| `Shift` + `1`–`9` | 메모로 입력 |
| `N` | 메모 모드 켜기/끄기 |
| 방향키 | 칸 이동 (트랙패드 클릭으로도 선택) |
| `Backspace` | 지우기 |
| `Z` / `⌘Z` | 실행 취소 |
| `H` | 힌트 |
| `,` | 설정 열기 (`Esc`로 닫기) |
| 새 게임 창에서 `1` `2` `3` | 쉬움 / 보통 / 어려움 |

GitHub Pages로 배포했다면 `…/killer-sudoku/`로 열고 공유 → "홈 화면에 추가"를 하면 전체 화면 앱처럼 실행됩니다.
